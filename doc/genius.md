# 天才主意

## 无死锁的安全少拷贝额外线程地图计算
通常, 要开一个额外线程计算地图有下列步骤: 
- 把东西从地图里复制到缓冲区
- 在缓冲区里计算
- 把算好的东西从缓冲区复制到地图上

这个步骤有很多问题. 由于最后这个步骤并不能在额外线程里去做, 然而地图可能很大, 要是复制时间有些长, 可能就会拖累主线程的渲染帧周期. 

而我们的办法是这样的:

首先有一些预先步骤:
- 开一个有两个地图大的缓冲区 (分成两块, 我们不妨叫它们是0号和1号)
- 指定最开始的地图是第一个缓冲区 (0号缓冲区)

开额外线程的时候, 做这些事情:
- 如果地图在0, 那就把0复制到1. 否则反过来.
- 在被复制到的那个区域进行计算
- 返回计算区域的地址.

详细来说, 这玩意运行起来就是这样一个效果:
- 地图在0, 开额外线程, 线程在1进行计算, 与此同时主线程在0渲染
- 然后线程返回, 并开线程, 线程开始在0进行计算, 但是主线程已经在1渲染了. 
- 0和1依次接力地图状态, 渲染和计算总是不在一个缓冲区上. 

每一个步骤都可以在额外线程里去完成. 最后在主线程, 只需要拷贝计算区域的地址到地图地址中即可, 由于地址的大小可以忽略不计, 带来的影响也很少.
